# QUANT – โปรแกรมจำลองความเสี่ยงในการลงทุนหุ้น

โครงงานวิชา PE104 ใช้ภาษา Python และเปิดใช้งานผ่าน Terminal

โปรแกรมนี้ช่วยทดลองดูว่า ถ้าเราลงทุนในหุ้น เราอาจได้กำไรหรือขาดทุนได้มากแค่ไหน โดยใช้ราคาหุ้นในอดีตมาคำนวณและจำลองผลลัพธ์หลาย ๆ รอบ

> โปรแกรมนี้ทำขึ้นเพื่อการเรียนรู้เท่านั้น ไม่ใช่คำแนะนำในการซื้อหรือขายหุ้น

## 1. โปรแกรมนี้ทำอะไรได้บ้าง

1. อ่านข้อมูลราคาหุ้นย้อนหลังจากไฟล์ CSV หรือดึงข้อมูลจาก Yahoo Finance
2. คำนวณผลตอบแทนรายวัน ว่าราคาหุ้นเพิ่มขึ้นหรือลดลงกี่เปอร์เซ็นต์
3. คำนวณความผันผวน เพื่อดูว่าราคาหุ้นเปลี่ยนแปลงมากหรือน้อย
4. จำลองผลการลงทุนด้วยวิธี Historical Bootstrap Monte Carlo โดยสุ่มผลตอบแทนจากข้อมูลในอดีตหลาย ๆ รอบ
5. ประเมินความเสี่ยง เช่น โอกาสขาดทุน (Probability of Loss), Value at Risk (VaR) และ Maximum Drawdown (MDD)
6. แสดงผลใน Terminal และบันทึกรายงานไว้ในไฟล์ข้อความ
7. เปิดดูรายงานที่เคยสร้างไว้ได้

## 2. ไฟล์แต่ละไฟล์ทำหน้าที่อะไร

- `main.py` – ไฟล์หลัก แสดงเมนู รับค่าจากผู้ใช้ และเรียกไฟล์อื่นให้ทำงาน
- `data_analysis.py` – อ่านและจัดการข้อมูลราคาหุ้น รวมถึงคำนวณผลตอบแทน
- `simulation.py` – คำนวณความผันผวนและจำลองผลการลงทุน
- `risk_report.py` – คำนวณความเสี่ยงและสร้างรายงาน
- `sample_data/stock_prices.csv` – ข้อมูลหุ้นตัวอย่างสำหรับทดลองแบบไม่ใช้อินเทอร์เน็ต
- `data/cache/` – ที่เก็บข้อมูลหุ้นที่ดาวน์โหลดจากอินเทอร์เน็ต
- `reports/risk_report.txt` – รายงานผลการวิเคราะห์ล่าสุด
- `docs/` – เอกสารข้อกำหนด แผนทดสอบ บันทึกการใช้ AI และสิ่งที่ได้เรียนรู้

ไฟล์ทั้ง 4 ไฟล์ทำงานร่วมกัน โดย `main.py` เป็นตัวเรียกใช้งาน ไม่ได้นำโค้ดของทุกคนไปรวมไว้ในไฟล์เดียว

## 3. สิ่งที่ต้องติดตั้ง

- Python 3.9 ขึ้นไป
- อินเทอร์เน็ต เมื่อต้องการใช้เมนูดึงข้อมูลหุ้นจริง
- ไลบรารี `yfinance` สำหรับดึงข้อมูลจาก Yahoo Finance

ติดตั้งไลบรารีด้วยคำสั่งนี้ใน Terminal:

```bash
python3 -m pip install -r requirements.txt
```

ส่วนการอ่านไฟล์ CSV การคำนวณทางคณิตศาสตร์ การสุ่ม และการจัดการไฟล์ ใช้เครื่องมือที่มีมาให้ใน Python อยู่แล้ว

## 4. วิธีเปิดโปรแกรม

เปิด Terminal ในโฟลเดอร์หลักของโครงงาน แล้วพิมพ์:

```bash
python3 main.py
```

ถ้าเครื่องของคุณใช้คำสั่ง `python` สำหรับ Python 3 ก็สามารถพิมพ์ `python main.py` ได้

## 5. เมนูในโปรแกรม

| เมนู | ทำอะไร |
|---|---|
| 1 | วิเคราะห์หุ้นโดยดึงข้อมูลจาก Yahoo Finance ต้องใช้อินเทอร์เน็ต |
| 2 | เปิดดูรายงานที่เคยบันทึกไว้ |
| 3 | ทดลองวิเคราะห์ด้วยข้อมูลหุ้น AAPL ที่อยู่ในเครื่อง ไม่ต้องใช้อินเทอร์เน็ต |
| 0 | ออกจากโปรแกรม |

เมื่อเลือกเมนู 1 หรือ 3 โปรแกรมจะถามเงินลงทุน จำนวนวันที่ต้องการจำลอง และจำนวนรอบที่ต้องการจำลอง

## 6. โปรแกรมคำนวณอย่างไร

### ผลตอบแทนรายวัน (Daily Return)

นำราคาปิดของวันนี้มาเทียบกับราคาปิดของวันก่อนหน้า เพื่อดูว่าราคาเปลี่ยนไปกี่เปอร์เซ็นต์

`(ราคาวันนี้ ÷ ราคาวันก่อนหน้า) - 1`

### ความผันผวน (Volatility)

ใช้ดูว่าผลตอบแทนของหุ้นขึ้นลงมากน้อยแค่ไหน โปรแกรมคำนวณความผันผวนต่อปีโดยใช้จำนวนวันซื้อขายประมาณ 252 วัน

### การจำลอง Monte Carlo แบบ Historical Bootstrap

โปรแกรมสุ่มหยิบผลตอบแทนจากข้อมูลในอดีตมาใช้สร้างผลลัพธ์ในอนาคตหลาย ๆ แบบ ทำซ้ำตามจำนวนรอบที่ผู้ใช้กำหนด การสุ่มเป็นแบบใส่คืน จึงมีโอกาสสุ่มได้ค่าซ้ำ

### ค่าความเสี่ยง

- **Probability of Loss** – โอกาสที่มูลค่าเงินลงทุนตอนจบจะน้อยกว่าเงินเริ่มต้น
- **VaR** – ค่าประมาณการขาดทุนตามระดับความเชื่อมั่นที่กำหนด ในโครงการนี้ใช้ 95%
- **MDD** – เปอร์เซ็นต์การลดลงจากจุดที่มูลค่าพอร์ตเคยสูงที่สุด

## 7. ข้อจำกัดของโปรแกรม

- ราคาหุ้นในอดีตไม่ได้บอกผลตอบแทนในอนาคตได้แน่นอน
- การจำลองเป็นเพียงการประมาณ ไม่สามารถครอบคลุมเหตุการณ์ในตลาดได้ทั้งหมด
- โปรแกรมยังไม่รวมค่าธรรมเนียม ภาษี และค่าใช้จ่ายในการซื้อขาย
- การดึงข้อมูลจริงขึ้นอยู่กับอินเทอร์เน็ตและการให้บริการของ Yahoo Finance
- ข้อมูลใน `sample_data` มีไว้สำหรับทดลองโปรแกรม ไม่ใช่ราคาหุ้นล่าสุด

## 8. การแบ่งงานของสมาชิก

- สมาชิก A ดูแล `data_analysis.py` จัดการข้อมูลหุ้นและคำนวณผลตอบแทน
- สมาชิก B ดูแล `simulation.py` คำนวณความผันผวนและจำลองผลการลงทุน
- สมาชิก C ดูแล `risk_report.py` ประเมินความเสี่ยงและสร้างรายงาน
- ทุกคนทำงานร่วมกันผ่าน `main.py` ซึ่งเป็นไฟล์หลักของโปรแกรม
