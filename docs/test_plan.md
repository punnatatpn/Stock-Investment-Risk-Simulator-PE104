# แผนการทดสอบและบันทึกผล (Test Plan)

เอกสารนี้ใช้สำหรับจดบันทึกผลหลังจากทดลองเปิดโปรแกรมจริงบนเครื่องของเรา ให้ทำตามขั้นตอนทีละข้อ แล้วเขียนสิ่งที่เห็นบนหน้าจอลงในช่อง **ผลที่เกิดขึ้นจริง** ด้วยคำพูดของเราเอง

**สำคัญ:** อย่าใส่คำว่า PASS (ผ่าน) จนกว่าจะทดลองจริงแล้ว และอย่าคาดเดาผลแทนการทดลอง

## 1. เตรียมก่อนทดสอบ

1. เปิด VS Code หรือ Terminal ไปที่โฟลเดอร์หลักของโปรเจกต์
2. ดึงโค้ดล่าสุดให้เรียบร้อยด้วยคำสั่ง `git pull origin main`
3. เปิด Terminal แล้วรัน `python3 main.py`
4. เตรียมจดผลและถ่ายภาพหน้าจอในแต่ละกรณีที่สำคัญ
5. ถ้าจะทดสอบโดยย้ายหรือแก้ไฟล์ ให้สำรองไฟล์เดิมไว้ก่อน และนำกลับคืนทันทีหลังทดสอบ

## 3. วิธีกรอกผลหลังทดสอบ

- **ผลที่เกิดขึ้นจริง:** เขียนสิ่งที่โปรแกรมแสดงจริง เช่น “โปรแกรมแจ้งให้กรอกจำนวนเต็มใหม่ แล้วรับค่า 10 ได้”
- **สถานะ PASS:** ใช้เมื่อผลจริงตรงกับผลที่ควรเกิดขึ้น
- **สถานะ FAIL:** ใช้เมื่อผลจริงไม่ตรงกับที่คาด หรือโปรแกรมเกิดข้อผิดพลาด
- **ชื่อภาพหลักฐาน:** ใส่ชื่อไฟล์ภาพที่ถ่ายไว้ เช่น `T06_offline_demo.png`
- ถ้าทดสอบแล้วพบปัญหา ให้จดปัญหาไว้ แก้ไขโค้ด แล้วทดลองกรณีนั้นซ้ำอีกครั้ง

## 4. การเก็บภาพหน้าจอ

แนะนำให้สร้างโฟลเดอร์นี้ไว้ในโปรเจกต์:

```text
docs/
├── requirements.md
├── test_plan.md
├── ai_log.md
├── lessons.md
├── version_history.md
└── screenshots/
    ├── T01_exit.png
    ├── T02_wrong_menu.png
    ├── T03_invalid_money.png
    ├── T06_offline_demo.png
    └── T07_previous_report.png
```

ไม่จำเป็นต้องถ่ายทุกข้อถ้าภาพซ้ำกัน แต่ควรมีภาพที่เห็นหลักฐานสำคัญ ได้แก่ การออกจากโปรแกรม การกรอกข้อมูลผิด การรัน Demo สำเร็จ การแสดงรายงาน และการแจ้งเตือนเมื่อไม่มีไฟล์

บน Mac กด `Command + Shift + 4` แล้วลากเลือกบริเวณหน้าจอ Terminal ที่ต้องการจับภาพ ภาพจะถูกบันทึกตามตำแหน่งตั้งต้นของเครื่อง (โดยทั่วไปคือ Desktop) จากนั้นย้ายไฟล์ไปไว้ใน `docs/screenshots/`
