# แผนการทดสอบและผลการทดสอบโปรแกรม

เอกสารนี้บันทึกการทดสอบโปรแกรม QUANT จากภาพหน้าจอที่สมาชิกแคปไว้จริงทั้งหมด 11 ภาพ

**หมายเหตุ:** สถานะ PASS ในตารางนี้หมายถึงภาพที่แนบแสดงผลตรงตามสิ่งที่ต้องการทดสอบ หากมีการแก้โค้ดหลังจากวันที่ทดสอบ ควรรันทดสอบซ้ำกับเวอร์ชันล่าสุดก่อนส่งงาน

## ภาพหลักฐาน

ภาพหน้าจอทั้งหมดอยู่ในโฟลเดอร์ `docs/screenshots/` โดยใช้ชื่อไฟล์ตามลำดับการทดสอบ ตั้งแต่ `testครั้งที่ 1.png` ถึง `testครั้งที่ 11.png`

## สรุปผล

จากภาพหน้าจอทั้ง 11 ภาพ โปรแกรมแสดงพฤติกรรมตามที่ทดสอบ ได้แก่ การออกจากโปรแกรม การจัดการข้อมูลที่กรอกผิด การทดลองด้วยข้อมูลตัวอย่าง การสร้างและเปิดรายงาน การจัดการแถว CSV ที่ผิดรูปแบบ และการดึงข้อมูลหุ้นจาก Yahoo Finance

**ข้อควรทำก่อนส่ง:** ให้ทดลองรันโปรแกรมอีกครั้งหลังจากกู้คืนไฟล์ CSV และดึงโค้ดล่าสุดแล้ว เพื่อยืนยันว่าผลการทดสอบยังตรงกับเวอร์ชันที่จะส่งอาจารย์
